FastTracker 2.08 (Triton)
(by MadProcess / Kaotyk Breïn)

After a 2.07 version that did not bring anything new to FastTracker, Triton finally decided to make the software much better in version 2.08

Wave sample load:

Get rid of these hazardous convertions using Convert or SoundForge (Gravis Patches)! Adding to this, FT2 allows you to choose left or right channel, and thus to load them seperately, or to mix them to one mono sample.

Nonetheless, don't hesitate to convert stereo files with SoundForge (antialias filter).

Diskwriter:

Only Cubic had the diskwriter function (and Mod4win) which could be precisely parametered (stereo/mono, 16/8bits, volume, etc.) FastTracker 2.08 now allows you to choose the length of the recording (in patterns), and where to start the recording.

This solution is much more practical than using Cubic as some of FT2's "bugs" are not in Cubic (ie: a "note off" when there is no volume envelope set will be a "volume set to 00" in FT2, whereas Cubic will use the amplitude envelopes decay, even if it is not set).

All Triton now needs to include is a diskwriter function with sample mute, allowing you to record ONLY one sample which could then be used in a dedicated software (Cubase VST, Cakewalk 6) with effects applied.

New mixing routines for SB16 (32bits):

This is the real revolution. Finally the SB16 owners will have a decent sound, although it still is not as good as the gravis utlrasound sound. It's better not to use too much channels on a slow computer (486), but this was already a restriction on FT 2.08.

MIDI for the SB16:

As I don't have a SB16, I couldn't test this function, nonetheless, it should be working (hopefully...)

What's still missing:

Well, there'll always be people asking for more :). Triton still did not add the GUS PnP support, which means you are still limited to 1M samples (although the card accepts 8M) and 16 channels at 44khz. After 16 channels, the mix will be made in 22khz, then 11 and finally 8! And there still is no AWE32 support (AWE64 now...)

I hope there will be a FT3 which will make the software at least as good as Impulse tracker or Velvet Studio Pro.
