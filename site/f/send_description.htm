Description de démo

pour que ta démo qui a été releasée hors-party apparaisse dans la rubrique démos, envoie les éléments suivants à ojuice@???? :

- nom de la démo
- nom du groupe
- codeur(s)
- graphiste(s)
- zikos
- DOS extender et/ou OS
- routines sonores si non propriétaires (ex: MIDAS)
- cartes sons supportées
- système vidéo (VESA, DirectX, ...), modes vidéos
- description objective en anglais
- de 0 à 4 snapshots (cf. à droite)
- adresse inet de l'archive (de préférence sur hornet ou arosnet, sinon s'assurer de sa pérennité)

  





snapshots: compris dans 100x75 pixels, maximum 4096 octets. (conseil: compression en jpg progressif, taux 15 sous PSP 4.12). chacun peut être accompagné d'une version taille réelle (en général 320x240) de maximum 35 ko (conseil: compression jpg progressif, taux 10 sous PSP 4.12) qui apparaitra en cliquant sur le snapshot. stocke les dans le mail en file attach (pas de uuencode ou jehnsaitrokoi)
